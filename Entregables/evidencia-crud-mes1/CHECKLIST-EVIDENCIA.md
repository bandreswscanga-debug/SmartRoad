# Checklist final de entrega

## Repositorio y colaboración — 20%

- [ ] URL real de GitHub/GitLab.
- [ ] Historial visible de varios integrantes.
- [ ] Commits del último mes.

## CRUD — 40%

- [ ] Colección Postman importada.
- [ ] GET para las cinco entidades.
- [ ] POST para las cinco entidades.
- [ ] PUT para las cinco entidades.
- [ ] DELETE para las cinco entidades.
- [ ] Respuestas 200/201/400/404/409 visibles.

## Persistencia — 30%

- [ ] Tabla antes de la prueba.
- [ ] Misma tabla después de la prueba.
- [ ] Dato de Postman idéntico al dato de MySQL.

## Scrum — 10%

- [ ] Tablero real captura.
- [ ] Historias de configuración, login y CRUDs en Terminado.
- [ ] Fecha de actualización visible.
