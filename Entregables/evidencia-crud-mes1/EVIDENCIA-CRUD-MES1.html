Repositorio central: https://github.com/bandreswscanga-debug/SmartRoad. Completar los nombres de los integrantes.

  2. Entrar a History / Commits.
  3. Filtrar el último mes.
  4. Capturar autores, fechas y mensajes de al menos dos integrantes.
  5. Guardar como 01-git-historial-ultimo-mes.png.

3.2 Colección Postman

Importar en Postman:

Entregables/evidencia-crud-mes1/postman/SmartRoad-SOS-CRUD.postman_collection.json
Entregables/evidencia-crud-mes1/postman/SmartRoad-SOS-Local.postman_environment.json

La colección contiene 29 solicitudes: creación de la cadena, lecturas, actualizaciones, validaciones negativas y eliminación inversa.

MétodoRutaUso
GET/api/conductorListar conductores
POST/api/conductorCrear conductor
PUT/api/conductor/:idActualizar conductor
DELETE/api/conductor/:idEliminar conductor

Las mismas cinco operaciones existen para vehiculo, dispositivo, evento y alerta.

3.3 Ejecución recomendada

cd /home/oswal/SmartRoadSOS/backend
pnpm install
pnpm db:setup
pnpm start

curl http://127.0.0.1:4000/api/health
curl http://127.0.0.1:4000/api/conductor
  1. Crear conductor.
  2. Crear vehículo con el ID del conductor.
  3. Crear dispositivo con el ID del vehículo.
  4. Crear evento con el ID del dispositivo.
  5. Crear alerta con el ID del evento.
  6. Consultar y actualizar cada entidad.
  7. Probar campo faltante, FK inexistente, duplicado 1:1 y registro inexistente.
  8. Eliminar en orden inverso.

  2. Seleccionar smartroad_sos.
  3. Capturar la tabla antes de insertar: 10-db-conductor-antes.png.
