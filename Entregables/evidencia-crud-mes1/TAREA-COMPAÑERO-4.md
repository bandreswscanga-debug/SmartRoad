# Tarea simple para el compañero/a 4

## Rama

```bash
evidencia/parte-4-evidencias
```

No necesita programar ni modificar el backend.

## Tarea

### 1. Ejecutar Postman

Importar la colección:

```text
postman/SmartRoad-SOS-CRUD.postman_collection.json
```

Usar valores únicos:

```text
unique_tag = ENTREGA-20260924-04
placa_tag = P60924D
```

Ejecutar las carpetas 01, 02, 03 y 04. No ejecutar la carpeta 05 hasta tomar las capturas de la base de datos.

Tomar 3 o 4 capturas de Postman mostrando:

- POST 201.
- GET 200.
- PUT 200.
- Validación 400.

### 2. Tomar capturas de MySQL

Abrir:

```text
http://127.0.0.1:8080
```

Base:

```text
smartroad_sos
```

Tabla:

```text
conductor
```

Guardar:

```text
10-db-conductor-antes.png
11-db-conductor-despues.png
```

### 3. Organizar evidencia

Crear una carpeta llamada:

```text
evidencia-companero-4
```

Guardar allí las capturas y el archivo:

```text
SmartRoad-SOS-CRUD.postman_collection.json
```

No incluir contraseñas, `.env` ni tokens.
